# The Second Chapter

**To add a chapter**, create a new file in this `chapters` folder, e.g. `03-third-chapter.md`, starting with a `# Heading` line. Chapters appear in filename order, so number them `01-`, `02-` … `10-`.

**To keep a draft out of the book**, start its filename with `draft-` (e.g. `draft-05-idea.md`). Rename it when it's ready.
